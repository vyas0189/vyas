# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/vyas0189/vyas/security/advisories/new)
for this repository. Don't open a public issue or pull request for a security
problem.

Include what you found, where (page, endpoint or file), and steps to reproduce.
You'll get a reply as soon as possible, and a fix for a confirmed issue ships
with the next deploy.

## Supported versions

This is a personal website that deploys continuously from `main`. Only the
live site at https://vyasr.space and the current `main` branch are supported.

## Scope

In scope: the site, its contact form API (`/api/emails`), and this
repository's code and workflows.

Out of scope: third-party services the site uses (Netlify, Resend, Sentry);
report those to their vendors.
